# XLM-R balanced5

Исследовательский детектор AI-текста на русском, английском, немецком, французском и китайском. Зафиксированы веса balanced5 и исходные пороги отдельно для каждого языка (`balanced5_frozen`).

## Скачать модель и запустить

**[Полный комплект с весами — выпуск balanced5-20261111](https://github.com/LDY55/xlmr-balanced5/releases/tag/balanced5-20261111)**: архив `xlmr_balanced5_release_20261111.zip`, 1 130 040 554 байта. Репозиторий и выпуск закрытые; для скачивания нужен доступ к этому репозиторию.

В разделе **Assets** скачайте архив, распакуйте его и откройте папку `xlmr_balanced5`. Далее выполните команды из [инструкции запуска](xlmr_balanced5/README.md). В комплект входят веса, токенизатор, пороги, проверка файлов и код запуска на CPU. Вызовы внешних API для проверки текстов не нужны.

При работе через GitHub CLI архив можно скачать так:

```shell
gh release download balanced5-20261111 --repo LDY55/xlmr-balanced5 --pattern xlmr_balanced5_release_20261111.zip
```

Git хранит исходники, токенизатор и результаты; большой файл `model/model.safetensors` находится в архиве выпуска. Если вы клонировали репозиторий, можно скопировать этот файл из архива в `xlmr_balanced5/model/` и выполнять команды из папки `xlmr_balanced5`.

## Независимый от обучения и калибровки тест

4 213 коротких отзывов: 1 500 человеческих текстов Amazon MARC/RuReviews и 2 713 AI-переписываний Qwen3-1.7B/Gemma 4 E2B. Таблица объединяет оба генератора внутри языка; каждый человеческий текст учитывается один раз. Пороги зафиксированы до этого теста. Отказы: 0.

| Язык | Полнота | FPR | ROC-AUC | PR-AUC | AP | CPU, мс/текст |
|---|---:|---:|---:|---:|---:|---:|
| Русский | 11.19% | 0.33% | 0.7406 | 0.8030 | 0.8034 | 30.7 |
| Английский | 18.68% | 0.33% | 0.8543 | 0.9228 | 0.9229 | 22.1 |
| Немецкий | 19.79% | 0.67% | 0.8320 | 0.9003 | 0.9004 | 22.6 |
| Французский | 24.09% | 0.67% | 0.8895 | 0.9390 | 0.9391 | 21.1 |
| Китайский | 27.50% | 1.00% | 0.8782 | 0.9262 | 0.9263 | 19.8 |


FPR — доля человеческих текстов, ошибочно отмеченных как AI. PR-AUC — площадь под кривой precision–recall методом трапеций; AP — average precision. PR-AUC/AP зависят от доли AI в тесте. Подробный состав и исключённые копии описаны в [инструкции](xlmr_balanced5/README.md).

Скорость измерена на всех 4 213 текстах: Intel Core i7-14700KF, Windows, 8 потоков, пакет 8. Обработка заняла 96,83 с: 22,98 мс/текст, 43,51 текста/с. Токенизация включена; загрузка весов и прогрев исключены. Это скорость пакетной обработки коротких отзывов. Решения совпали с исходным GPU-прогоном на всех текстах.

**Цель полноты ≥50% при FPR ≤5% на всех языках пока не достигнута.** Выпуск является исследовательским. Версия выбрана после сравнения на уже изученном внешнем тесте; повторный CPU-прогон проверяет воспроизводимость и не является новой слепой проверкой. Более поздняя reviews5 ухудшила перенос и не включена как основная модель. AI-балл не является откалиброванной вероятностью происхождения текста.
