# XLM-R balanced5 — зафиксированная версия для передачи

Это исследовательский детектор AI-текста на русском, английском, немецком, французском и китайском. Передаются прежние веса balanced5 и их исходные языковые пороги. Более поздняя reviews5 не выбрана, поскольку ухудшила общий перенос на новые источники. Это выбор после сравнения на уже изученном внешнем тесте, а не новая слепая проверка готового выпуска. Цель полнота ≥50% при FPR ≤5% на всех языках не подтверждена.

## Состав и запуск
Python 3.11, 64 бита. Создайте отдельное окружение. Для Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe self_test.py
.venv\Scripts\python.exe check_text.py --lang ru --file input.txt --threads 8
```

`input.txt` — UTF-8 файл с вашим текстом. Без `--file` текст читается из стандартного ввода. Допустимые языки: `ru`, `en`, `de`, `fr`, `zh`. После установки зависимостей все веса и токенизатор загружаются локально; API не используется. Для Linux используйте Python 3.11 и `.venv/bin/python` в тех же командах. Установочные команды CPU соответствуют [инструкции PyTorch](https://pytorch.org/get-started/previous-versions/#v271). Выполненный замер использовал CPU-устройство в сборке torch 2.7.1+cu128; отдельная установка CPU-wheel здесь не проверялась.

Из Python:
```python
from pathlib import Path
from detector import XLMRDetector
model = XLMRDetector(Path('model'), device='cpu', threads=8)
print(model.check('Здесь ваш текст для проверки.', language='ru', batch_size=8))
```

Результат: `score` (AI-балл), `logit`, языковой `threshold`, `decision`, количество фрагментов `windows`, время вызова `ms`. `ai_candidate` — превышение порога; `below_threshold` — ниже порога; `abstain` — недостаточно букв. Балл не откалиброван как вероятность происхождения. Флаги воды и спама в эту модель не входят.

## Архитектура и обучение
Общий XLM-R base, 12 слоёв, размер скрытого представления 768, бинарная голова HUMAN/AI. Инициализация от исходного пятиъязычного пилота; полный цикл balanced5 обучен на 14 912 текстах DetectRL-X News/Novel/Webtext/Wiki/Academic, AI: GPT-4o и Qwen-Max. Выбор версии — 2 964 документа, калибровка — 3 449 человеческих текстов. Выбрана эпоха 2. Длинные тексты обрабатываются целиком окнами по 382 содержательных токена; усредняются разности AI/HUMAN-логитов, затем sigmoid. Порог отдельный для языка.

Весовой SHA-256: `6a5b4b5cffe66d3fb55ec8eebfcfeeabfd3eaa3087cae6d94efa40dc38eb176e`.
Основа: [FacebookAI/xlm-roberta-base](https://huggingface.co/FacebookAI/xlm-roberta-base), MIT; исходное уведомление включено в LICENSE-XLMR.txt. Данные и их собственные условия описаны в документации исходных корпусов.

## Независимый от обучения тест
4 213 документов: 1 500 исторических человеческих товарных отзывов Amazon MARC (EN/DE/FR/ZH) и RuReviews (RU), 2 713 переписываний Qwen3-1.7B/Gemma 4 E2B. Исходники не использованы для дообучения или выбора порогов; выполнены exact/near проверки против доступной истории. Исходный предтрейн XLM-R полностью проверить невозможно. Qwen3 — новый checkpoint, но семейство Qwen представлено в обучении Qwen-Max; Gemma — новое семейство.

280 копий исходника с точностью до регистра/пунктуации и 7 ответов на другом языке исключены. У русского Qwen3 осталось 111 AI-переписываний из 300; у Gemma 300. Отдельная проверка с копиями находится в `evaluation/metrics_with_copied_returns.csv`.

`evaluation/metrics_by_language.csv` объединяет оба генератора внутри языка и учитывает каждого человека ровно один раз. Поэтому доля AI превышает 50%; PR-AUC/AP следует сравнивать при одном составе выборки. Отдельные генераторы — `metrics_by_generator.csv`; все баллы CPU без текстов — `cpu_predictions.parquet`. Пороги точно соответствуют `model/thresholds.json`, вариант в прежнем исследовании — `balanced5_frozen`.

## Скорость и проверка
Весь тест реально пересчитан на CPU: Intel Core i7-14700KF, Windows, 8 вычислительных потоков, пакет 8. Токенизация включена, загрузка весов и прогрев отдельно. 4213 документов, 96.828 с, в среднем **22.983 мс/документ**, **43.51 документа/с**. Это время документа в пакетной обработке, не задержка одиночного запроса и не скорость на одном ядре. Один полный проход на этом компьютере; нагрузка других процессов не контролировалась.

Решения CPU совпали с исходным GPU-прогоном на всех 4213 документах. Максимальная разность логитов 0.00036080182. `self_test.py` проверяет хеши и вычисления на пяти коротких синтетических примерах; это программный тест, не оценка качества.

Полные условия и время по языкам — `evaluation/full_cpu_benchmark.json` и `cpu_speed.csv`. В `evaluation/benchmark_original_project.py` сохранён исходный код проведённого замера для проверки методики. Это архив кода из проекта: он требует исходного test.parquet, pandas, pyarrow, scikit-learn и исходного расположения проекта (`work/xlmr_delivery_20261111/benchmark.py`); для проверки собственных текстов используйте переносимый `check_text.py`.
